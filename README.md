# Ponder

Free, open-source (MIT) AI learning platform. Desktop-first, starting on macOS.

See `docs/IDEAS.md`.

## Languages

The interface is available in English, Chinese (Simplified and Traditional), Hindi, Spanish, French, Arabic, Bengali, Portuguese (Brazil), Russian, Urdu, Indonesian, German, Japanese, Turkish, Korean, Vietnamese, Italian, Polish and Persian. Arabic, Urdu and Persian are shown right to left. Pick the language in Settings or during setup.

English is the source. The other languages are machine-translated with a shared glossary per language and an automatic back-translation check; German was reviewed by hand. If a translation is wrong or awkward, fix it in `src/locales/<code>.json` and open a pull request (see `CONTRIBUTING.md`).
